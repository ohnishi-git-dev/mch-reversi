## 1. 概要

本仕様は、3つの共有リバーシ盤面を順番に進行させ、各盤面に配置したヒーローのスキルで局面を補助・妨害する CPU 戦向け MVP を定義する。

MVP では通常のリバーシの読み合いを主軸にし、スキルは「石を置く代わりに使う戦術選択」として扱う。スキルによる直接配置や石の反転は行わない。

## 2. ゲーム構成

### 2.1 プレイ人数

- MVP はプレイヤー対 CPU のソロプレイを主対象とする。
- 対人戦は将来拡張とし、MVP 仕様には含めない。

### 2.2 盤面

- 左、中央、右の3つの共有盤面を使用する。
- MVP の盤面サイズは 6x6 とする。
- 将来的に 8x8 へ拡張できる設計にする。
- 各盤面の初期配置は通常リバーシと同じ中央4石配置とする。

### 2.3 ヒーロー配置

- プレイヤーと CPU は、それぞれ左、中央、右の各盤面に1体ずつヒーローを配置する。
- 試合中のヒーロー入れ替えは不可。
- 自軍内の同一ヒーロー重複配置を許可する。
- プレイヤーと CPU が同じヒーローを同時に使用することも許可する。
- 終局済み盤面の担当ヒーローはスキルを使用できず、スキル対象にもならない。

## 3. 試合開始

### 3.1 先後決定

- コイントスでプレイヤーと CPU に黒/白をランダムに割り当てる。
- プレイヤーが白になった場合、最初の手番は CPU の黒手番から開始する。

### 3.2 CPU ヒーロー選択

- CPU は MVP ヒーロープールから3枠をランダムに選ぶ。
- CPU も重複選択を許可する。

### 3.3 スキルゲージ初期値

- 全ヒーローのスキルゲージは 0 から開始する。
- スキルゲージ最大値は 10。
- 全スキルの使用コストは 10。

## 4. ターン進行

### 4.1 面順

ターンは以下の順に進む。

```text
黒 左面
白 左面
黒 中央面
白 中央面
黒 右面
白 右面
黒 左面
...
```

終局済みの盤面は以後の面順からスキップする。

### 4.2 手番で選べる行動

手番プレイヤーは、現在アクティブな盤面に対して次のどちらかを選ぶ。

1. 現在盤面に石を置く
2. スキルゲージが満タンの味方ヒーロー1体のスキルを使用する

スキルは石を置く代わりに使用する。スキルを使用した場合、その手番では石を置かずに終了する。

### 4.3 スキル使用者

- スキルゲージが満タンで、かつ担当盤面が未終局の味方ヒーローであれば、現在盤面の担当ヒーロー以外でもスキルを使用できる。
- 例: 黒の左面手番で、黒の中央ヒーローのスキルを使用できる。
- その場合でも消費される手番は「黒の左面手番」とする。

### 4.4 パス

- 合法手がなく、使用可能なスキルもない場合は自動パスする。
- 合法手がある場合でも、使用可能なスキルを石を置く代わりに使える。

## 5. スキルゲージ

### 5.1 増加条件

スキルゲージは、石を置いた場合のみ増加する。スキル使用ターンや自動パスターンでは増加しない。

増加対象は、実際に石を置いた現在盤面の担当ヒーローのみとする。

### 5.2 増加量

| 条件 | 増加量 |
| --- | ---: |
| 石を置いた | +1 |
| 返した石2枚ごと | +1 |
| 角に置いた | +2 |
| 辺に置いた | +1 |

増加後の値は最大 10 でクリップする。

## 6. スキル共通ルール

### 6.1 共通制約

- スキルコストは全ヒーロー共通で 10。
- 1手番に使用できるスキルは1つのみ。
- スキル対象は3面どこでも選択可能。
- 直接石を置くスキルは禁止。
- 石を反転させるスキルは禁止。
- スキルに有効な対象が存在しない場合、そのスキルは使用不可。
- スキル効果は終局済み盤面には適用できない。

### 6.2 対象選択 UI

プレイヤーのスキル使用は、次の流れを基本とする。

```text
スキル選択
対象盤面選択
対象マスまたは対象ヒーロー選択
確定
```

CPU は難易度ごとの評価ロジックに従って対象を選ぶ。

## 7. スキル効果タイプ

### 7.1 自石/相手石の保護

- 対象盤面にある自石または相手石1枚を指定して保護する。
- 保護は、その盤面が一巡するまで継続する。
- 例: 黒の手番で左面の石を保護した場合、白の左面手番を経て、次の黒の左面手番開始時に解除する。
- 保護石を含むラインが反転対象になった場合、保護石だけが反転せず、他の反転対象石は通常通り処理する。
- 相手石を保護した場合、その盤面の自分の次手番で石を配置した後に保護を無効化する。
- 盤面が終局した場合、その盤面上の保護効果は即時消滅する。

### 7.2 相手合法手マスの封鎖

- 対象盤面における相手の合法手である空きマス1つを指定する。
- 封鎖されたマスは、対象相手だけが置けない。
- 封鎖は相手の次のその盤面手番まで継続する。
- 相手がその盤面でスキルを使用した場合も封鎖は解除される。
- 封鎖によって相手の合法手がすべて消えた場合、相手は自動パスする。
- 盤面が終局した場合、その盤面上の封鎖効果は即時消滅する。

### 7.3 味方ゲージ配布

- 自分以外の味方ヒーロー1体を対象に、スキルゲージを +8 する。
- 対象は担当盤面が未終局の味方ヒーローに限る。
- 増加後の値は最大 10 でクリップする。

### 7.4 相手ゲージ減少

- 敵ヒーロー1体を手動選択し、スキルゲージを -5 する。
- 対象は担当盤面が未終局の敵ヒーローに限る。
- 減少後の値は下限 0 でクリップする。

## 8. MVP ヒーロープール

MVP では `bearko/mycryptoheroes` のレジェンダリーヒーローから6体を採用する。スキル名と効果はリバーシ向けに再設計する。

| ヒーロー | スキル名 | 系統 | 効果 |
| --- | --- | --- | --- |
| 織田信長 | 天下布武 | 封鎖 | 対象盤面の相手合法手マスを1つ封鎖する。 |
| ナポレオン・ボナパルト | 戦術展開 | ゲージ配布 | 自分以外の味方ヒーロー1体のスキルゲージを +8 する。 |
| 曹操 | 乱世の奸雄 | ゲージ減少 | 敵ヒーロー1体のスキルゲージを -5 する。 |
| ジョージ・ワシントン | 大陸軍の守り | 保護 | 対象盤面の自石または相手石1枚を保護する。 |
| レオナルド・ダ・ビンチ | モナリザの幻惑 | 封鎖 | 対象盤面の相手合法手マスを1つ封鎖する。角マスは選択不可。 |
| ジャンヌ・ダルク | オルレアンの加護 | 保護 | 対象盤面の自石または相手石1枚を保護する。辺の石のみ選択可。 |

同系統スキルは今後調整予定だが、MVP では強くなりすぎないよう効果量を固定寄りにする。

## 9. CPU

### 9.1 難易度

MVP では `easy`、`normal`、`hard` の3段階を用意する。

| 難易度 | 方針 |
| --- | --- |
| easy | ランダム寄りに合法手とスキルを選ぶ。 |
| normal | 角、辺、石数、合法手数、スキル効果を簡易評価して選ぶ。 |
| hard | 1〜2手先読みとスキル評価を組み合わせて選ぶ。 |

### 9.2 CPU スキル

- CPU もプレイヤーと同じスキルルールに従う。
- CPU は使用可能なスキルがあっても、評価上不利であれば通常手を選んでよい。

## 10. 終局と勝敗

### 10.1 盤面終局

各盤面は、通常リバーシと同じく「両者とも石を置けず、かつ使用可能なスキルもない」状態で終局する。

終局した盤面は、その時点の石数で勝敗を判定する。同数の場合はその盤面を引き分けとする。

### 10.2 試合勝敗

- 先に2面を勝利した側が即勝利する。
- 引き分け面はどちらの勝ちにも数えない。
- 2面先取が発生せず、全盤面が終局した場合は総石数で勝敗を判定する。
- 総石数も同点の場合は試合引き分けとする。

## 11. MVP 対象外

- 対人戦
- パッシブスキル
- スキルによる石の直接配置
- スキルによる石の反転
- 試合中のヒーロー入れ替え
- 8x8 盤面
- レジェンダリー全ヒーロー対応
- ヒーローごとのスキルコスト差
- ヒーローごとのゲージ獲得量差
